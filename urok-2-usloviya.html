Как работать с уроком

Запускайте кодВ каждом разделе есть редакторы с жёлтой кнопкой «Запустить». Нажмите её — программа выполнится, а результат появится в тёмном поле «Вывод».
Поле «Ввод»Если программа вызывает input(), впишите значения в поле «Ввод» — по одному на строку: первая строка для первого input(), вторая для второго. Если поле пустое, Python покажет окно ввода.
Отступы важныВ этом уроке команды внутри if, elif и else пишутся с отступом в четыре пробела. Убираете отступ — выходит из ветки. Это не стиль, а часть языка: без отступа Python не запустит программу.
Всё сохраняетсяКод, ввод и отметки о решённых задачах сохраняются в вашем браузере. Можно закрыть страницу и вернуться позже — всё останется на месте.
КонструкторКнопка «Конструктор» в шапке включает режим редактирования: меняйте любой текст, код, задачи и целые разделы. Все правки автоматически сохраняются в этом браузере и восстановятся при следующем открытии страницы.

Зачем нужны условия

10 минут

Программы учатся принимать решения: действовать по-разному в зависимости от данных.

В жизни мы постоянно действуем по схеме «если — то»: если на улице дождь — берём зонт, если дождя нет — не берём. В программировании то же самое делает конструкция if («если»):

if условие:
    действие

Python проверяет условие: если оно истинно — выполняет команду с отступом, если ложно — пропускает её и идёт дальше. Запустите пример:

В «Выводе» появилось Можно: условие age >= 18 истинно. А теперь измените первую строку на age = 15 и запустите снова — программа ничего не напечатает. Это не ошибка: условие ложно, и Python просто пропустил print(). «Молчание» программы — тоже результат.

Главное правило. После условия ставится двоеточие :, а действие записывается с отступом — четыре пробела. Отступ показывает Python, какая команда относится к условию. Без отступа программа не запустится, а неровные отступы — самая частая ошибка новичка.
Важно для ЕГЭ. На экзамене проверяют именно аккуратность: двоеточие в конце строки с if и одинаковый отступ у всех команд ветки. Потренируйтесь писать отступы руками — так быстрее запоминается структура.

Операторы сравнения

10 минут

Условие — это вопрос с ответом «да» или «нет». Задаём его операторами сравнения.

Внутри if стоит выражение, которое Python проверяет на истинность. Для сравнения чисел и строк есть шесть операторов:

ОператорЗначениеПримерРезультат
>больше7 > 3истина
<меньше2 < 1ложь
>=больше или равно5 >= 5истина
<=меньше или равно4 <= 3ложь
==равно6 == 6истина
!=не равно6 != 4истина
Не перепутайте. = и == — не одно и то же! Один знак — записать значение в переменную: x = 10. Два знака — спросить, равно ли: x == 10. Если в условии написать один знак, Python остановится с ошибкой SyntaxError.

Мини-практика: что выведет программа?

Сначала ответьте мысленно, потом запустите и проверьте. Первая:

Верно: A — десять больше пяти, условие истинно. Вторая:

Вывод пустой: x < 5 — ложь, print() не выполнился. Найдите минуту и проговорите, почему в первом случае ответ «A», а во втором — тишина: это и есть механика условий.

elif: несколько вариантов

10 минут

Когда вариантов больше двух, между if и else ставят elif — «иначе, если».

Программа проверяет условия сверху вниз: первое истинное — выполняет его ветку и пропускает все остальные, даже если те тоже подходят. Посмотрите на оценку за тест:

При вводе 84 сработает ветка Хорошо: первое условие (84 ≥ 90) ложно, второе (84 ≥ 70) — истинно. Замените ввод на 95 — условие score >= 90 окажется первым истинным, и Python даже не заглянет в elif.

if
 ↓
условие 1?
 ├─ да → действие
 └─ нет
      ↓
   elif
      ↓
условие 2?
 ├─ да → действие
 └─ нет
      ↓
    else
Порядок важен. Python выполняет только первую подошедшую ветку. Ставьте сначала более строгие условия: если написать score >= 70 раньше score >= 90, то даже 95 получит «Хорошо» — до «Отлично» очередь не дойдёт.

Логические операции

10 минут

and, or и not — собираем сложные условия из простых.

Часто одного условия мало: «возраст от 18 до 30» — это сразу две проверки. Простые условия соединяют словами and («и»), or («или») и not («не»):

ОперацияИстинна, когдаПример
andоба условия истинныage >= 18 and age <= 30
orистинно хотя бы одноday == 6 or day == 7
notусловие ложно (отрицание)not n == 0

and — «и то, и другое»

Возраст подходит, если он одновременно не меньше 18 и не больше 30. Измените возраст на 33 — второе условие станет ложным, и вся связка and рухнет:

or — «хотя бы что-то одно»

Выходной, если день равен 6 или 7 — достаточно одного совпадения. Попробуйте 3, 6 и 7:

not — отрицание

Операция not меняет результат на противоположный: истина становится ложью и наоборот. Например, «если число не нулевое»:

if not n == 0:
    print("Число не нулевое")
На заметку. Сегодня достаточно уверенно пользоваться and и or. not встречается реже — вернётесь к нему, когда он понадобится в реальной задаче.

Практика в стиле ЕГЭ

15 минут

От простых проверок — к экзаменационному мышлению: данные меняются по условию.

В задачах ЕГЭ условие чаще всего не просто печатает ответ, а изменяет данные: число увеличивается, делится, заменяется. Разберём три классических сюжета.

Задача 8.1Плюс одинВвод: 5 → 6; −2 → −2

Вводится число. Если оно положительное — увеличить его на 1, иначе оставить без изменений. Вывести результат.

Показать решение
n = int(input())

if n > 0:
    n = n + 1

print(n)

Обратите внимание: print(n) стоит без отступа — он общий для обеих веток и выполняется всегда. Если сдвинуть его внутрь if, при отрицательном вводе программа ничего не напечатает. Проверьте оба варианта.

Задача 8.2Половина или утроениеВвод: 8 → 4; 7 → 21

Вводится число. Если оно чётное — разделить его на 2, иначе умножить на 3. Вывести результат.

Показать решение
n = int(input())

if n % 2 == 0:
    n = n // 2
else:
    n = n * 3

print(n)
Задача 8.3НаибольшееВвод: 7 и 9 → 9

Вводятся два числа. Вывести большее из них.

Показать решение
a = int(input())
b = int(input())

if a > b:
    print(a)
else:
    print(b)
А если числа равны? При a == b условие a > b ложно, и сработает else — программа напечатает b. Это то же самое число, поэтому формально ответ верный. Но если равенство — отдельный случай с отдельным ответом, нужна третья ветка: вы потренируете её в задаче 9.6.

ДЗ 3.1ПалиндромВвод: 121 → Вывод: Да; 123 → Нет

Подсказка: первая цифра числа — это n // 100, последняя — n % 10. У трёхзначного палиндрома первая и последняя цифры совпадают — средней можно не заниматься.
Показать решение
n = int(input())

if n // 100 == n % 10:
    print("Да")
else:
    print("Нет")
Идеальное решение не обязательно. Палиндром — задача-мостик к следующей теме «цифры числа». Если получилось не идеально, но ответ верный для трёхзначных чисел — засчитано. Разбор — на следующем занятии.
